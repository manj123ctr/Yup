# Yup

This repository contains:

* **`vice-coast/`**: *Vice Coast*, an original open-world crime game that runs in the browser (Three.js). See [`vice-coast/README.md`](vice-coast/README.md) for how to run it, the controls and a full feature list.
* **`index.html`**: *Surge Steward*, a standalone single-file browser game.

Quick start for Vice Coast:

```bash
cd vice-coast && python3 -m http.server 8000
# open http://localhost:8000
```
